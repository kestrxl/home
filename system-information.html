Windows System Information

Two ways to collect computer specifications for support.

Quick GuidesWeb ResourcesWindows ToolsMacros & ControlsSystem InformationMac ResourcesAndroid

Keyboard-only method

  1. Press Windows + R.
  2. Type msinfo32, then press Enter.
  3. Press Ctrl + A, then Ctrl + C.
  4. Paste the information directly into an email.

Mouse method

  1. Open Start, then Settings.
  2. Select System and open About.
  3. Copy Device specifications and paste them into the email.
  4. Copy Windows specifications and paste them into the email.
  5. Go to System, then Storage.
  6. Include each drive’s total size and available space.
